# Воронка трудоустройства — правила

## Цель
Удалённая работа из России, в том числе на зарубежные компании:
- Junior / Junior+ React/TypeScript frontend developer
- Junior / Junior+ HTML/CSS layout developer

## Фильтры
- Россия: от 60 000 RUB/месяц.
- Международные вакансии: от 1 000 USD/месяц или эквивалент.
- Если зарплата не указана — сохранять как salary_unknown, не выдавать за подтверждённую.
- Junior, Junior+, entry-level; допускается требование опыта до 3 лет, если стек и задачи подходят. Исключать стажировки/trainee, Middle, Senior, Lead.
- Удалёнка по России; гибрид/офис — только Екатеринбург. Не предлагать QA, поддержку, операционные и операторские роли.
- Исключать обязательный SQL и вакансии, не допускающие работу из России.
- Worldwide/remote само по себе не доказывает возможность работы из России.
- Удалять дубликаты по компании, роли и URL.
- Не отправлять отклики, если условия не подтверждены или требуют недостоверных сведений.

## Воронка
discovered -> screened -> matched -> prepared -> submitted_verified -> reply -> interview -> offer
Также: rejected, blocked, needs_human, salary_unknown.
Статус submitted_verified устанавливать только при наличии подтверждения платформы или успешной отправки письма; отсутствие ошибки не достаточно.

## Резюме
React: проекты VKMarusya, AudioPlayer, TravelBlog.
Вёрстка: Landing-page, Lighting-store, адаптивная вёрстка.
Персонализировать письмо под требования, без выдуманных навыков.

## Отчётность
Считать найденные, прошедшие фильтры, подготовленные, подтверждённо отправленные, ответы, интервью, офферы; отдельно ошибки и ручные действия. Уведомления Telegram без ложного утверждения об отправке.

## Режим откликов
Пользователь разрешил автоматическую отправку всех подходящих откликов без индивидуального согласования (12 октября 2026). Это разрешение распространяется на Россию и международные вакансии, удовлетворяющие условиям выше. При капче, необходимости входа, неподтверждённой географии, неясной зарплате или юридических вопросах — статус needs_human, без фиктивного подтверждения отправки.
