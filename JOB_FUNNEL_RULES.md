# Воронка трудоустройства — актуальные правила

## Цель
- Junior / Junior+ Frontend React / TypeScript.
- Стажировки по frontend, включая оплачиваемые и неоплачиваемые.
- HTML/CSS-вёрстка — вторичный приоритет.
- QA, поддержка, продажи, операционные и операторские роли не являются целевыми.

## География и формат
- Кандидат находится в Екатеринбурге, Россия; гражданство РФ и право работать в России.
- Удалённая работа допустима из России.
- Гибрид допустим только в Екатеринбурге.
- Офис / on-site исключается везде.
- Переезд и командировки не допускаются.
- Международная удалённая вакансия проходит только при явном подтверждении, что работодатель нанимает кандидатов, проживающих в России. Worldwide / remote без такого подтверждения недостаточно.
- Явное ограничение на проживание или право на работу в другой стране блокирует вакансию.

## Зарплата
Все суммы нормализуются к месячному эквиваленту, если период указан явно.

| Тип вакансии | Допустимый диапазон |
|---|---:|
| Стажировка / internship / trainee | 0–50 000 RUB в месяц включительно |
| Обычная Junior / Junior+ | 50 000–70 000 RUB в месяц включительно |

- Стажировки включаются независимо от оплаты; 0 RUB допустимо.
- Для стажировки без указанной зарплаты вакансия остаётся допустимой.
- Для обычной Junior / Junior+ вакансии без зарплаты — только ручная проверка, не автоматическое принятие.
- Если диапазон пересекает границу допустимой зарплаты или период/валюта неясны — ручная проверка.
- Зарплата выше верхней границы исключает вакансию.
- Нельзя считать неизвестную зарплату подтверждённой.

## Навыки и опыт
- Подтверждённый стек: React, TypeScript, JavaScript, Redux Toolkit, React Router, REST, Axios, HTML5, CSS3, SCSS, Git, адаптивная вёрстка.
- Next.js, Jest и React Testing Library — направления обучения, не подтверждённый коммерческий опыт.
- SQL не добавлять в подтверждённый стек; обязательный SQL исключает вакансию, явно необязательный не блокирует.
- Не приписывать коммерческий опыт, навыки или проекты, которых нет в резюме.
- Исключать Middle / Senior / Lead, обязательные неподдерживаемые фреймворки и роли вне целевого профиля.

## Приоритет источников
- Вакансии трудоустройства — приоритет.
- Фриланс — резервный канал, только если нет подходящих вакансий трудоустройства.
- Не использовать платные ставки, кредиты и подписки.
- Не обходить CAPTCHA, авторизацию, антибот-защиту или ограничения площадок.

## Воронка и безопасность
discovered -> screened -> matched -> prepared -> submitted_verified -> reply -> interview -> offer

Дополнительные статусы: rejected, blocked, needs_human, salary_unknown.

- Неизвестные условия, неясная география, зарплата обычной Junior-вакансии без подтверждения, CAPTCHA или необходимость ручной авторизации переводятся в needs_human.
- submitted_verified устанавливается только при достоверном подтверждении платформы или успешной отправки письма.
- Поиск, ранжирование и подготовка отчёта не означают, что отклик отправлен.
- Лимиты и проверки дублей должны применяться до любой отправки.
