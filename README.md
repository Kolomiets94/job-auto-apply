# Job Auto Apply

Портфолио-проект для поиска и предварительного отбора вакансий Junior Frontend (React/TypeScript, HTML/CSS) и отдельных фриланс-задач. Код собирает публичные объявления из нескольких источников, ранжирует их по заголовку, указанному стеку, уровню и совпадению с резюме, а затем отправляет отчёт в Telegram.

## Правила отбора

- Цель: Junior Frontend / React / TypeScript и вёрстка; вакансии «от 1 года» допускаются, если это явно указано в данных.
- Исключаются стажировки, Middle/Senior, Vue, Angular, Full Stack, React Native и Flutter.
- Обязательный SQL исключается; явно необязательный SQL («будет плюсом») не блокирует вакансию.
- QA-объявления могут появляться в отчётах, но автоотклики QA приостановлены.
- Полные требования некоторых источников недоступны из выдачи; поэтому соответствие недоступным требованиям нельзя подтвердить автоматически. Ранжирование не является гарантией соответствия.

## Playwright

Браузерная автоматизация реализована через Playwright (Chromium), без Selenium. Версия Python-пакета Playwright зафиксирована в `requirements.txt`. Для локальной установки браузера:

```bash
python -m pip install -r requirements.txt
python -m playwright install --with-deps chromium
```

Проверки безопасности остаются включёнными: CAPTCHA/Turnstile, двухфакторная авторизация и неизвестные вопросы работодателя не обходятся. При таких условиях автоматизация останавливается и помечает вакансию для ручного действия.

## Render

В репозитории есть `Dockerfile` и `render.yaml` для бесплатного Render Web Service в регионе Frankfurt. Docker-образ основан на официальном образе Playwright с Chromium и системными библиотеками.

- Web Service запускает Flask через Gunicorn.
- `DRY_RUN=1`, `AUTO_BROWSER_APPLY=0` и `AUTO_SEND_EMAIL=0` выставлены безопасными значениями по умолчанию: первый деплой только собирает вакансии и формирует черновики.
- `HUNTER_RUN_TOKEN` генерируется Render. Защищённый POST `/run` запускает один проход; заголовок: `Authorization: Bearer <HUNTER_RUN_TOKEN>`.
- `DATABASE_URL` можно задать в настройках Render для PostgreSQL. Без неё используется локальная SQLite, которая на Free Web Service не является постоянным хранилищем.
- Автоматическое расписание не создаётся: Render Cron Jobs не имеют бесплатного тарифа. Для периодического запуска нужен платный Render Cron Job или отдельный внешний планировщик. GitHub Actions в этой конфигурации не используются.

**Ограничения бесплатного Render:** Web Service засыпает после 15 минут без входящих запросов, локальные файлы теряются при перезапуске/сне/деплое, а бесплатный Render Postgres действует 30 дней. Free Web Service также ограничен 512 MB RAM; запуск Chromium может оказаться слишком тяжёлым. Поэтому сначала проверьте сборку и тестовый запуск в режиме черновиков, прежде чем включать реальные отклики.

## Черновики, отклики и отчёты

Сопроводительное письмо составляется на основе подтверждённых личных проектов с прямой ссылкой на код. Оно не утверждает коммерческий опыт и не приписывает навыки, которых нет в портфолио. В режиме `DRY_RUN=1` реальные отклики не отправляются. После проверки можно отдельно настроить каналы отправки и авторизацию; не храните секреты в репозитории. Telegram используется для отчётов о фактическом результате. Бот считает найденные, отобранные, пропущенные и отправленные объявления и сообщает причины в сводке.

## Количество откликов

Часовые и дневные ограничения количества по умолчанию отключены: `DAILY_JOB_LIMIT`, `DAILY_FREELANCE_LIMIT`, `HOURLY_JOB_LIMIT`, `HOURLY_FREELANCE_LIMIT` равны `0`. Пустое значение окружения также означает отсутствие лимита; положительное число снова включает соответствующую квоту. Проверка повторных откликов сохраняется.

## Локальный запуск

```bash
pip install -r requirements.txt
python worker.py
```

Для локального веб API:

```bash
gunicorn app:app --bind 0.0.0.0:10000
```

Основные защищённые endpoints: `/jobs`, `/freelance`, `/queue`, `POST /run`. Для них нужен `HUNTER_RUN_TOKEN` в заголовке `Authorization: Bearer ...`.

Поиск охватывает Россию и международные источники; международные вакансии проходят только при явно указанной доступности из России либо worldwide/anywhere/global и без ограничений права на работу. Повторные отклики исключаются. Перед реальным использованием проверьте источники, фильтры, авторизацию и правила конкретной площадки.
